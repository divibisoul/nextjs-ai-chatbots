# N04 continuation

The repository is the source of truth. Every future operation must first inspect the current branch/commit and accumulated directives, then mutate the repository only where a concrete divergence is found. No conversational declaration substitutes for a GitHub change.

Current invariant: capability registration is introspectable through `registeredCapabilities()` and `missingCapabilities()`, enabling automated detection of incomplete registration without deleting existing runtime behavior.

## Cumulative master execution layer

N04 participates in the six-front SOUL engineering process. Work from other conversations may already exist in GitHub; inspect it before making changes. Preserve compatible work and build on it rather than restarting.

N04 remains an independent IA and Super-GPU execution nucleus. Its agents, capabilities, tools, context and execution facilities must be composable with peer nuclei through the canonical Soul Mesh and negotiated hybrid transports.

## Failure-antibody invariant

Every actionable finding is corrected immediately rather than merely reported. The mandatory loop is:

`DETECT → DIAGNOSE → RESEARCH → CORRECT → COMPLETE → CONNECT → OPTIMIZE → VALIDATE → DOCUMENT → RE-AUDIT`

This applies to missing, incomplete, fragile, disconnected, duplicated, mocked, unregistered, unexposed, unused or inconsistent implementation. A failed first solution is not completion; investigate and apply the next viable alternative unless a real technical blocker or incompatibility is demonstrated.

## Cross-front handoff

Every completed increment must leave enough repository evidence for another parallel front to continue without conversational memory: what changed, what was found, what remains, what should happen next, affected capabilities/agents/tools, dependencies, compatibility and validation/commissioning state.

## Fusion invariant

Pair and higher-order work is capability composition. Before declaring a connection complete, cross-check complementary agents, tools, capabilities, context and execution paths and record technically justified emergent capabilities. Keep execution distributed and independently deployable.
